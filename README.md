## 🎯 **What Is This?**

A **high-performance 3D simulation** built in Godot 4 that generates **labeled synthetic data** for training autonomous AI agents. Perfect for robotics research, reinforcement learning, and computer vision applications.

**Built for:** Technical Artist / Simulation Engineer roles in AI research

---

## ✨ **Key Features**

| Category | Capabilities |
|----------|--------------|
| **Engine** | Godot 4.2 with Forward+ renderer |
| **Performance** | 120+ FPS, <500MB RAM |
| **Data Export** | JSON state history + RGB frames + depth data |
| **ML Ready** | Python scripts to load, visualize, and train models |
| **Deterministic** | Reproducible simulation for research validation |
| **Controls** | WASD movement, E to export, R to reset |
